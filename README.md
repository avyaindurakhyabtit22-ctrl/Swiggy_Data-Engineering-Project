# Swiggy_Data-Engineering-Project
Swiggy_Data Engineering Project: Built an end-to-end Snowflake Data Warehouse using SQL, AWS S3, and Streamlit. Implemented Medallion Architecture, SCD Type 2 dimensions, Fact &amp; Dimension modeling, KPI views, and an interactive dashboard for revenue and restaurant analytics, with data validation, recovery, and relationship integrity checks.
